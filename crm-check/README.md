# crm-check — синтетическая страница проверки

Не CRM и не данные. Страница открывается в окне CRM **тестовой** сборки «SAinst Practice Check» и показывает
на экране, что окно CRM не может обратиться к сейфу и командам программы (проверка B1 №7). Ничего не отправляет.
Источник: приватный репозиторий приложения, `tools/windows-check/crm-check/`.
